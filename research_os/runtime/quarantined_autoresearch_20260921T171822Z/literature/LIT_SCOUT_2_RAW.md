# NOVELTY_THREATS

1. **Unverified — source-boundary threat:** Without the actual audit, claim matrix, and scope, N1–N6 cannot be mapped to precise claims. Any stronger mapping would risk inventing the proposal rather than auditing it.

2. **Unverified — relabeled claim-verification threat:** If N1 merely converts crypto posts into true/false, supported/unsupported, or entailed/not-entailed labels, the task is standard claim verification with a new domain.

3. **Unverified — argument-mining relabeling threat:** If N2 predicts support, attack, stance, agreement, or disagreement links, calling the links “opinion propagation” does not establish a new NLP task.

4. **Unverified — explanation-as-attribution threat:** If N3 only returns important tokens, features, nodes, or edges from an already trained predictor, it is feature attribution unless interventions demonstrate faithfulness or causal usefulness.

5. **Unverified — graph-forecasting threat:** If N4 predicts the next counterparty or edge from historical graph state, the central task is temporal link prediction/event forecasting; an Ethereum setting alone is domain novelty.

6. **Unverified — future-information leakage threat:** Wallet profiles, follower/following edges, tweets, labels, candidate pools, or aggregated graph statistics created after the prediction timestamp could make the apparent forecasting improvement invalid.

7. **Unverified — candidate-support threat:** If sampled candidates omit the true next counterparty for some examples, MRR, Hits, or Recall can be inflated or become undefined. Support coverage must be reported before any ranking claim.

8. **Unverified — calibration-after-the-fact threat:** If calibration maps, confidence thresholds, or abstention rules are tuned on the test period, reported reliability or risk–coverage results are post-test optimization rather than held-out evaluation.

9. **Unverified — selective-prediction relabeling threat:** A fixed reasoning-token or API-call budget does not demonstrate selective prediction unless the system explicitly chooses when to abstain and is compared at matched coverage and cost.

10. **Unverified — missing-NLP-centrality threat:** If graph-only features match the full model and no linguistic label, evidence judgment, argument relation, or text intervention is required, the NAACL story collapses to graph construction plus forecasting; the smallest surviving claim is not NLP novelty.
