# Open-world anomaly direction: novelty map (preliminary)

**Status:** boundary map only; not a completed dated title/abstract/code/data overlap audit.

## Established neighboring families to treat as non-novel alone

- supervised or weakly supervised Bitcoin/Ethereum fraud, AML, and illicit-account detection;
- static or temporal GNN fraud/anomaly detection;
- graph contrastive/self-supervised learning for anomaly detection;
- unsupervised community, motif, cycle, fan-in/fan-out, and flow-pattern detection;
- graph autoencoders, Node2Vec/DeepWalk anomaly scores, and density/outlier methods;
- LLM-generated pseudo-labels or free-form explanations without intervention/future validation.

The project must not claim novelty from merely combining "Ethereum + GNN + anomaly" or
"LLM + graph explanation".

## Candidate differentiating combination (unverified)

```text
open-world temporal group discovery
  -> selective reasoning-worthiness routing
  -> structured latent-strategy hypotheses
  -> support-removal / irrelevant-intervention verification
  -> falsifiable future-consistency validation
```

This is a research hypothesis, not a novelty claim. It becomes publishable only if each
stage adds measurable value beyond the simpler ladder and survives temporal replication,
matched controls, and external-label evaluation that never informs training or model
selection.

## Required follow-up audit before a paper claim

For each closest paper record title/date, task, graph granularity, labels, temporal split,
open-world setting, group discovery, intervention test, future validation, LLM use,
code/data availability, and minimal runnable evidence. Do not write "no one has done this"
until that dated overlap audit is complete.
