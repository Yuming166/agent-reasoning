## 6. 关键结论（必须与边界一起引用）

1. **共识富集是真实的，但由活动量驱动**：B/A/C 3 方共识在 K=100 达 28 个钱包（≈1,760×
   随机期望），未来活动均值 lift 26.9×。但 B≈A_vol（ρ=0.93, Jaccard 0.46）意味着该共识
   主要验证"高活动钱包被多方法反复选中"，不是验证三个**独立**定义一致。
2. **D（IG）是真正的方法特有信号**：top-K 唯一性 94–100%、与 B/C/A 秩相关 0.2–0.4、
   top-K 重叠 1–4/100；但未来活动效用低（K=100: 72 vs B 458）且目标绑定（y_active30 的
   top-IG 是"可预测不活跃"）。若 Phase-II 的"关注"目标是**未来活跃/新边**，IG 不应作为主
   选择器；若目标是**信息密度/可预测性**（如主动学习、不确定性驱动抽样），IG 是独立维度。
3. **4 方共识不可作为强证据**：支持集仅 1,283；K≤100 时 4 方交集≈随机；K≥500 低于独立
   随机期望（方法间相关结构导致）。任何"四个方法都说重要"的叙事必须同时报随机期望与
   支持集边界。
4. **支持集不可外推**：C 只覆盖 7,929、D 只覆盖 2,999、4 方交集 1,283；所有共识数字均为
   支持集受限口径。B/A-vol 覆盖全 18,519。
5. **共识 ≠ 正确性**：fwd30 是标签层验证（描述性）；没有独立 ground truth 说"这些钱包
   '真'重要"；共识只说明"多个 proxy 在活动维度上相互印证"。
