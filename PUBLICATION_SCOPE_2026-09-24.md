# EX-Graph publication scope — 2026-09-24

This commit publishes the current reproducible research artifacts for the EX-Graph Ethereum project.

## Included

- Phase II-A reasoning-worthiness reports, preregistered feature contracts, rerun scripts, compact selector tables, manifests, bootstrap results, cross-model summaries, adversarial audits, and paper figures.
- OW-010B open-world protocol, preregistration, aggregate reports/results, and rerun code.
- Decision-State V1 protocol, literature audit, aggregate effectiveness/degradation reports, compact metrics, and audit code.

## Excluded intentionally

- Raw or event-level BigQuery extracts, address-level panels, prompt/case tables, frozen LLM panels, model predictions/features, parquet datasets, raw tweet/text data, external-label extracts, Astra/Luna relay responses or caches, credentials, local environments, logs, and runtime residue.
- Large source artifacts such as `ethereum_graph.gpickle` and private/private-relay configuration.

The public artifacts preserve the reported result boundaries. In particular, the repository does not claim causal wallet influence, real wallet-owner beliefs/intent, a completed K-step market simulator, or universal LLM superiority.
