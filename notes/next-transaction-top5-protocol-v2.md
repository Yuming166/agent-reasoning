# 未来交易活动与下一目标地址 Top-5：任务与教师—学生协议 v2

**版本日期：2026-09-30。** 本版承接历史 v1 的任务与评测分母，但取代其中“LLM 只能看截止前历史生成假说”的方法设定。训练阶段的回溯教师可以看到训练标签；开发和测试阶段的学生、候选器与排序器只能看到截止前历史。因子发现与伪标签的来源、可验证性和使用边界以本版为准。本文自含执行所需的任务定义，上传时不依赖 v1 文件。

## 1. 预测对象与任务标签

- 一个实例为 `(wallet, cutoff_utc)`，截止时间为 `t`。模型可见的事件、图边、地址库和元数据必须在 `t` 前已经存在。预测窗为 `[t, t+7 days)`，评测 cutoff 的标签窗不得重叠。
- **Eligible transaction：**钱包作为 `from` 发出的 `external_tx`，`to` 地址非空。合约调用和零 ETH 金额交易包含在内；没有 `to` 的合约创建不进入主任务。失败交易的纳入规则必须在建标签前审计和冻结。历史中的 token transfer/internal trace 可作特征，不是独立的未来目标交易。
- **Task A：**未来窗内是否至少存在一笔 eligible transaction，记为 `y_active`。
- **Task B：**若 `y_active=1`，未来窗内按区块号、交易索引等规范键排序后的第一笔 eligible transaction 的 `to` 地址，记为 `y_dest`。同时间戳不能依赖文件顺序。
- 主任务是在 `t` 时输出活动分数和恰好 5 个互不重复、按置信度排序的目标地址。候选不足时用事先冻结的、只读历史的后备规则补足。合约地址可以是目标。本任务不等同于代币买卖预测、心理动机判断或投资建议。

## 2. 三个不同的信息边界

| 阶段/对象 | 可见信息 | 允许的产出 | 禁止事项 |
| --- | --- | --- | --- |
| 训练因子发现与回溯教师 | 训练 case 的 `H_<t`、训练标签 `y_active/y_dest`；预先定义的可执行原子操作 | 参数化因子提案、历史证据引用、训练伪标签与不确定性 | 把未来地址常量写入因子、把解释说成真实原因、读取 dev/holdout 标签来改因子 |
| 独立验证器 | 完整的训练历史与训练标签；冻结的因子语法 | 重新执行历史条件、检查时间和证据、计算结果相容性与反事实状态 | 让 LLM 自己声明“验证通过”或自己生成 certificate |
| 推断时学生/候选器/排序器 | 严格早于 `t` 的历史、图、截止前地址库和冻结模型参数 | 活动概率、因子分数、候选分数、Top-5 | 读取未来交易、教师回溯文本、未来活跃地址集合或测试标签 |

训练标签可参与**训练期监督**，但不能进入开发/测试时的特征路径。由训练结果得到的全局模型参数和抽象因子类型可以转移到推断；实例级教师解释和未来地址不能转移。每一层都有独立 as-of 审计。

## 3. 因子怎样生成：LLM 提议，程序编译与验证

本版不把八个手写名称当作最终因子全集。采用两层表示：

1. **冻结原子语法。** 先在不看测试结果的情况下定义可执行操作，例如 `count_events`、`last_seen`、`unique_counterparties`、`two_hop_paths`、`shared_contracts`、`temporal_trend`、`global_prior`，以及窗口、事件类型、方向、比较符和阈值的合法范围。明确区分钱包级 `F_wallet(H_<t)`（如活跃节奏）与候选级 `F_pair(H_<t, candidate)`（如与某候选地址的二跳路径）。所有操作只读 `H_<t`；输出都能由程序重算。原子语法是安全边界，不等于研究结论。
2. **LLM 在 train-discovery 提议组合因子。** 给它历史和已发生的训练动作，请它提出**多个竞争解释**，每条包含 `factor_name`、抽象 typed expression、适用前提、1–3 个历史 witness ID、预期行为方向和不确定性。允许提议原有因子以外的新组合，如“最近同协议多跳接近 + 近期活跃度跃升”，但禁止仅包含未来地址/单个钱包 ID 的专属规则。
3. **编译与合并。** 仅接受能编译进原子语法、参数在合法范围内且历史 witness 成立的提案；按规范化 AST 去重、合并同义表达。保留未通过提案及失败原因。因子不得因为在训练结果上显得好就跳过支持度和复杂度约束。
4. **跨样本稳定性筛选。** 在与发现集分开的 train-labeling 子集上检查因子支持数、覆盖、方向稳定性和结果相关性；与简单数值/图因子比较。这里的未来结果只用于**训练内部筛选和学习**，不能声称因子揭示实际原因。筛选阈值、最大因子数和语法版本在 dev/holdout 评测前冻结。
5. **教师标注训练样本。** 用冻结的因子目录在 train cases 上做回溯多标签标注，独立验证器计算历史条件成立、目标/活动结果相容、证据有效与否。`UNKNOWN` 是合法输出；未验证不等于假。伪标签可带置信度或 mask，但不能将含未来目标的实例文本/embedding传给学生。

一个最小 typed 因子例子：`count(external_tx.outgoing, target=candidate, window=30d) >= 2`。它描述可复算的重复交互模式；训练时可令 `candidate=y_dest` 来评估已发生目标是否满足该历史模式，**因子定义仍保留变量 `candidate`，不能把 `y_dest` 地址固化进表达式**。推断时对截止前检索出的每个候选分别执行同一因子。历史计数由程序算，未来相容性只用于训练期标注。类似 `two_hop_path`、`shared_contract` 等因子须有路径或合约证据；对无历史路径的新地址允许 `unsupported_new_target`，而不是编造连接。

**因子标签含义：**“历史中存在、与观察结果相容的可执行模式”。不能写成“这笔交易由该因子导致”，也不能用单个因子预测正确就反证其是真因。至少比较多标签、最强单标签、`UNKNOWN` 以及未验证教师标签。报告因子目录规模、各因子支持度、验证通过率、重复提案率与 train 子集稳定性。

## 4. 候选检索与学生的关系

候选生成在 `t` 时只使用历史。先比较钱包最近交互、频次、全网热门度与混合规则，再试时间衰减二跳、抑制 hub 的图统计、typed meta-path 和学习门控。候选必须记录来源与截止前证据。训练教师看到的真实目标不能被注入候选池；若未来地址在 cutoff 前全网不可见，主 Top-5 仍计失败并单报开放世界上界。

学生可采用共享历史编码器与三个头：`p_active`、因子权重、候选打分/检索权重。一个可检验的候选评分形式是 `base_score(w,c,t) + Σ_k α_k(w,t) F_pair,k(H_<t,c)`；这里 `α_k` 是学生仅凭历史预测的因子相关性，`F_pair,k` 是程序对候选 `c` 计算的历史证据。钱包级因子可进入活动头。所有排序消融先共享同一个截止前候选超集；若比较不同候选生成预算，另做检索实验。学生训练目标可写为 `L_activity + λ L_rank + μ L_factor`，其中因子损失只对已验证的训练伪标签计入，`λ/μ` 只在 dev 选择。真实训练目标不在候选池时，不得偷偷加入目标来计算 `L_rank`；这类 case 单列并在主评测计失败。

主对照包括：同架构无教师、验证教师、未验证教师、train 内打乱教师标签、仅数值/图因子、固定检索混合。所有 arm 使用相同 case、候选超集、模型容量和可比计算预算。只有主方法显著优于这些对照，才能把收益归因于经验证的教师监督；若它只改善因子解释质量而未改善预测，应如实区分。

## 5. 切分、指标与冻结门槛

- 已反复观察的 240 钱包及其 June/July/August 结果只作探索性诊断。正式 train/dev/holdout 排除这些钱包，并做到钱包隔离；如离线数据允许，再单独评估更晚时间窗。不能凭数据文件名声称时间外推。
- train 再划分 discovery、labeling/fit；因子目录不能用 dev/holdout 的未来结果发现或改写。dev 可选超参数、活动阈值和检索预算；holdout 仅在方法、prompt、因子目录与代码哈希冻结后做一次主要比较。
- Task A 在全部 wallet-cutoff cases 上报 AUPRC、Brier、AUROC、固定 dev 阈值下 balanced accuracy。Task B 在**全部 active cases** 上报 Recall@5 与 MRR@5，含候选未覆盖项。另报候选 `Recall@5/50/500/2000`、地址库可见上界、联合成功率、旧/新目标分层、钱包活跃度分层和配对置信区间。
- 预测遗漏以冻结 fallback 补全，不能改变分母。报告活动率、case 数、唯一钱包数、真实目标在候选空间内的数量、teacher 有效伪标签比例及成本。评估中不得把候选 Recall 写成最终 Top-5 命中率。
- 任意 cutoff 后边或 future-derived 地址过滤进入特征、跨 split 钱包重叠、标签窗口不完整、教师信息进入学生推断，均构成审计失败；修复前不得报告模型优劣。

## 6. v1 到 v2 的变更记录

| 项目 | v1 | v2 |
| --- | --- | --- |
| 任务 A/B 与 7 天标签 | 活动 + 第一目标 Top-5 | **保持** |
| 指标主分母 | 所有 case / 所有 active case | **保持** |
| LLM 输入 | 假说生成默认只看截止前历史 | **分阶段：**训练回溯教师可看训练未来，推断学生只看历史 |
| 因子来源 | 历史驱动假说，typed rule 验证 | **训练集 LLM 提议组合因子，程序编译/重算，冻结目录后蒸馏** |
| 解释含义 | 截止前可验证假说 | **与已观察结果相容的回溯模式**，不作因果或心理动机声称 |
| 控制实验 | 验证/未验证/打乱假说 | 加入**同架构无教师**和 discovery–labeling 分离 |

本协议不要求 LLM 直接给具体地址概率，也不把自然语言的流畅性当作预测能力。论文的 NLP 贡献若成立，应来自可执行因子发现、带验证的回溯伪标签，以及在看不到未来时可泛化的学生表示，而不是单次后见之明解释。
